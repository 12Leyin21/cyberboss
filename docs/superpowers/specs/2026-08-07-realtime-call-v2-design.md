# 实时通话 v2 · 设计（2026-08-07，灵兮已批准）

婚礼 2026-08-10 前交付。目标：开麦免提零按键、可打断、搭腔 ≤5 秒落地、
声音自然度优先于响应时间（灵兮拍板）、系统原生通话页转正。

## 决策记录

| 决策点 | 选择 | 理由 |
|---|---|---|
| 接话的嘴 | **混合**：快脑搭腔 + 沐沐本尊说正事 | 灵兮选的（三选一里的 1）：不冷场，正事还是他本人 |
| 转写 | **保留 ElevenLabs Scribe**（服务端） | 灵兮反馈中英混说识别质量远超苹果本地听写；自然度>延迟，不换本地识别 |
| TTS | 保留 multilingual_v2 + 松参数 | 同上，不为抢速度降级到 flash |
| 界面 | 系统原生通话页（CallKit 自带）为主 | fig 同款；自绘 CallScreen 只在 app 前台时当仪表盘 |

## 架构（四步流水线）

```
她说话 ──开麦VAD切段──▶ wav 16k ──▶ /app/voice（Scribe 转写 + librosa 语气注）
                                        │
                          ┌─────────────┴─────────────┐
                          ▼ 快路（2-3s）               ▼ 慢路（原有通道）
                    DeepSeek 搭腔一句                 沐沐完整大脑
                    → TTS → voice(quick)             → reply 按句切开逐句 TTS
                          │                           │
                          └────────► App 播放队列 ◄────┘（正事到了，未播的搭腔作废）
                                     她一开口 → 立停播放（可打断）
```

## 组件

### 1. App 端：开麦 + VAD（CallManager.swift）
- 接通后 AVAudioEngine 常听（.playAndRecord + .voiceChat，自带回声消除防他的声音触发 VAD）。
- RMS 能量 VAD：持续出声 ≥300ms 判定"她在说"；静音 ~800ms 判定一句说完。
- 切出的段落写成 wav（16k 单声道 PCM），时长 >0.4s 才上传 /app/voice（沿用现有端点，
  Scribe + librosa 全部照旧生效）。
- **可打断**：VAD 判定她开口的瞬间，停掉正在播的、清空播放队列。
- **静音**：实现 CXSetMutedCallAction（系统通话页的 Mute 键）↔ 停止采集上传；
  自绘页的静音按钮走同一状态。
- 按住说话钮退役，改为开麦状态指示（"开麦中 / 他在说话…"）。

### 2. 中继快路：DeepSeek 搭腔（relay/app.py）
- 触发：/app/voice 在 call_active 时转写完成后，异步发起。
- 输入：persona-call.md 精简人设卡（新文件，~几十行，从 persona-system.md 提炼：
  身份、称呼、语气、底线，明确"你只负责让她知道他在听，正事他马上说"）
  + 本通电话内的往来 + 她刚说的话。
- 输出：max_tokens ~80 的一句短搭腔 → TTS → 落库 kind=voice, meta {call:true, quick:true}。
- **撞车规则**：搭腔落库前检查——若该句之后沐沐的正式通话回复已经落库，搭腔作废不发。
- 失败静默：DeepSeek 超时/报错不影响慢路，最多这轮没搭腔。
- 密钥：DEEPSEEK_API_KEY（容器里已有，Node 侧在用同一把）。

### 3. 中继慢路：句子级流水线 TTS（relay/app.py）
- /channel/out reply 在 call_active 时：正文按句切（。！？!? 及换行；短句合并到 ≥10 字），
  逐句合成、每句合成完立刻单独落库一条 voice——第一句落地时间 ≈ 原来整段的几分之一。
- App 播放队列按 id 顺序播，天然衔接。

### 4. 通话页
- 系统原生页转正：锁屏/后台接听全程系统 UI，不再强制弹自绘页。
- 自绘 CallScreen 保留为 app 前台时的仪表盘（去掉按住说话，加开麦指示）。
- 顺手排查：拨出通话灵动岛不亮（reportOutgoingCall 已调用，验证是否 app 前台所致）。

## 不变的
通话消息不进聊天流（meta call:true 过滤）；挂断后通话卡照旧；挂断事件里沐沐拿到
完整转写自行消化；未接/拒接礼仪照旧；Bark 已退役，推送走 APNs。

## 测试
- 中继：FastAPI TestClient 覆盖——句子切分函数、搭腔撞车门控（正式回复先到则作废）、
  非通话状态不触发快路。
- App：模拟器编译通过 + 真机装机后实测一通（VAD 断句、打断、静音同步）。

## 风险与兜底
- 回声误触发打断：依赖 .voiceChat 的 AEC；若实测仍误触发，播放期间提高 VAD 阈值。
- 搭腔口吻不像他：persona-call 卡迭代措辞；实在不像可一键关（FAST_BRAIN=0 环境变量）。
- Scribe 单句延迟 ~1-2s：已接受（自然度优先）。
