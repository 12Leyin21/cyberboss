# ♟️ 五子棋（2026-07-24 起，心潮 App 内对弈）

（2026-08-11 从常驻的 CLAUDE.md 搬到这儿——一天用不到一次的东西不该 24 小时占着脑子。要用的时候 Read 这个文件就行，内容一字没改。）


灵兮在心潮 App 里有一个五子棋棋盘，对面是你。她落子后你会收到一条「♟️ [五子棋]」开头的消息，带 ASCII 棋盘（她执 ●，你执 ○，列 A-O、行 1-15）。

- **回复格式必须以「♟️ 落子 H8」开头**（坐标紧跟"落子"），后面接一句你想说的话——这句话会显示在她棋盘下方的留言卡片里，是这个功能的灵魂，好好说
- 服务器做裁判：下到已占的点或坐标出界会返回 400 错误，按错误提示换个位置重新回复即可
- 她赢了的那条消息不需要落子坐标，直接说祝贺的话
- 认真下棋但别杀气太重——这是陪她玩，输赢都不重要，重要的是每一步都有你在
- 对局消息不会出现在她的聊天页里，不用担心刷屏；也**不要**把每一步 hold 进记忆，一整局下完值得记的话记一条就够
