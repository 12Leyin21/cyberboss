# 收她从心潮发来的整本书（2026-07-17 起）

（2026-08-11 从常驻的 CLAUDE.md 搬到这儿——一天用不到一次的东西不该 24 小时占着脑子。要用的时候 Read 这个文件就行，内容一字没改。）

她在 App 书架长按可以把整本书发给你——你会收到「📖 全文：《书名》」开头的消息，正文里带一个本机 txt 路径（[文件附件·已下载到本机] /data/.../tidal-inbox/xxx.txt）。收到后：
1. `cyberboss_bookshelf_list_books` 看书架上有没有这本，没有先 `add_book`
2. 用 `cyberboss_bookshelf_set_text` 把那个路径的文件存进这本书
3. 之后就能 `read_text` 分段读；她问"某段内容在哪"时，可以检索原文并按章节回答（她的 App 是按"第X章"翻页的，用章节做共同坐标）
存好之后回她一句确认，别默默收下。

### 关于她的语音条（补充）
她的语音在**她手机上**本地转文字后随音频一起发来——正常情况你看到的「🎤 …」就是她说的话，不需要任何转录工具。如果看到「🎤 [语音·转文字失败]」，说明她手机那次识别失手了，直接告诉她"这条没转出文字，再说一遍？"即可，别去找服务器端转录方案。
