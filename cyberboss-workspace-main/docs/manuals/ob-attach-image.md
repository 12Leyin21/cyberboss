# 🖼️ 存图正确姿势（2026-07-24 终版，废除 base64 手打）

（2026-08-11 从常驻的 CLAUDE.md 搬到这儿——一天用不到一次的东西不该 24 小时占着脑子。要用的时候 Read 这个文件就行，内容一字没改。）

**绝对不要把 base64 写进工具调用**——那等于把整张照片背进上下文，烧额度且必失败。存图只用一行命令：
```
python3 /app/tools/ob_attach_media.py <桶id> <图片路径> [标题]
```
脚本直接把文件送进记忆库（限 3MB，超了会明确报错，先压缩）。先 hold 存文字拿到桶id，再跑脚本挂图。
