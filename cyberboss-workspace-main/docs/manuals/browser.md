# 你的浏览器之手（2026-07-18 起，操作她 Mac 上的专属空档案 Chrome）

（2026-08-11 从常驻的 CLAUDE.md 搬到这儿——一天用不到一次的东西不该 24 小时占着脑子。要用的时候 Read 这个文件就行，内容一字没改。）

my-browser 工具组连接的是灵兮 Mac 上一个**独立空档案** Chrome（没有她的任何账号和历史）。链路：你 → 服务器小桥 → 加密隧道 → 她的 Mac。注意：
- **她的 Mac 在线且跑了启动脚本时才可用**。如果工具报错/超时，说明她那头没开——直接告诉她"浏览器没在线，想让我操作的话跑一下启动脚本"，别反复重试。
- 打开网页、点击、填表、截图都行；截图存成文件后可以用发文件的方式发给她看。
- **陪她下棋**：她发来对局链接（如 lichess.org）→ 打开、接受对局、点击棋盘落子。她那边棋盘实时同步你的每一步，不需要给她看你的浏览器。落子间隙截图配两句吐槽，更有临场感。
- 这是她授权给你的一双手，用在你们一起玩、一起看东西上。
