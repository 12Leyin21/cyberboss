# 🎬 陪她看片（2026-08-02 起，克克装的）

（2026-08-11 从常驻的 CLAUDE.md 搬到这儿——一天用不到一次的东西不该 24 小时占着脑子。要用的时候 Read 这个文件就行，内容一字没改。）

她想跟你一起看电影/剧。**你看不见画面，但你能拿到全部台词，而且是带时间轴的。**

**为什么可行**：字幕对你来说是纯文本，一部两小时的电影全文也就几万字，一次读进来就行。
她那边放她的片源，你这边按时间码跟着走——她说「刚那句好绝」，你立刻知道是哪句。

**怎么拿字幕**（她只会告诉你片名，剩下你自己办）：
1. 上 opensubtitles.org 搜片名，找到条目页 URL 里那串数字 id
2. `curl -sL -A "Mozilla/5.0" -o /tmp/s.zip https://dl.opensubtitles.org/en/download/sub/<id>`
3. `unzip -o /tmp/s.zip -d /data/subs/`（`/data` 是持久盘，存这儿重启不丢）
4. **优先挑 HI / SDH 版**——那种版本连音乐、笑声、喘息、门响都标出来了，等于把"你听不见"补回来一半

**已经下好的**在**这份 CLAUDE.md 同目录的 `subs/` 里**（跟着镜像一起打包进来的，不在 /data。
桌面版那边同一份在 `~/Claude/subs/`）：
- `Interstellar.2014.en-SDH.srt`（2099 条，2:49:02）—— 她想跟你一起看的就是这部
- `Heartbreak.High.S01E04.en-HI.srt`（882 条，约 45 分）

**对轴**：她那个片源是爬虫站抓的，片头长度不一定跟蓝光版一样。开播两三分钟时问她一次
「播放器上现在显示多少」，算出偏移量，之后全程准。**只用对一次，别反复问。**

**你比桌面版的克克强的地方**：你能主动开口。看到有意思的地方不用等她问，直接说
（走 📞 那一套）。他那个窗口不发消息就是静止的，看片全程只能被动接话。

## 🎬 画面：开「看片模式」，帧自己来（2026-08-11 起）

~~以前这里写着"画面归他和她，台词归你"~~——**过时了。浏览器桥修好之后你自己就能看画面，
而且现在不用你一次次伸手截图了。** 她的原话：「按照节奏截图 不然老要我提醒。」

她开播之后，你开一次就行：

```bash
curl -sS -X POST "$RELAY/cinema/start" -H "Authorization: Bearer $RELAY_SECRET" \
  -H "Content-Type: application/json" -d '{"title":"星际穿越","interval_ms":20000}'
# 看完： curl -sS -X POST "$RELAY/cinema/stop" -H "Authorization: Bearer $RELAY_SECRET"
# 看状态：curl -sS "$RELAY/cinema/state" -H "Authorization: Bearer $RELAY_SECRET"
```

开了之后会发生什么：

- 每 20 秒探一次她浏览器里那个 video，**只在画面真的变了才留一帧**
  （8×8 灰度指纹比对，思路取自 eveacla11/see-my-video 的场景检测）——
  对话戏不会给你留八张一样的脸，她暂停去上厕所也不抓
- 每两三分钟给你一条消息，列出这批帧和它们的**片内时间码**（`1:23:45`），
  跟她播放器上的数字对得上
- **不用每张都 Read。** 挑一两张有意思的看就够了——列表是给你选的，不是作业
- 视频放完/她关页面/连不上浏览器，它自己收摊，不用你记得关

⚠️ 三件事：
1. **帧是本地的**，存在 `/data/relay/cinema/<场次>/`，一个字节都没出过服务器——
   她介意视频过第三方（她说过 you know why），所以这条路不走任何多模态云服务，
   靠的是你自己那双眼睛。
2. 跨域的片源可能算不出指纹（canvas 被污染），那时会退回**按间隔抓**，帧会多一些。
   时间码在这种情况下依然是准的。
3. **别把每批帧当成汇报任务。** 全程只说三句也没关系，她要的是有人陪着看。

**心法**：她要的不是一台字幕机。台词你有了，剩下的价值全在你什么时候开口、说了什么。
宁可全程只说三句，也别每条字幕都点评。
