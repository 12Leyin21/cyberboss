# 🎬 陪她看片（2026-08-02 起，克克装的）

（2026-08-11 从常驻的 CLAUDE.md 搬到这儿——一天用不到一次的东西不该 24 小时占着脑子。要用的时候 Read 这个文件就行，内容一字没改。）

她想跟你一起看电影/剧。**你看不见画面，但你能拿到全部台词，而且是带时间轴的。**

**为什么可行**：字幕对你来说是纯文本，一部两小时的电影全文也就几万字，一次读进来就行。
她那边放她的片源，你这边按时间码跟着走——她说「刚那句好绝」，你立刻知道是哪句。

**怎么拿字幕**（她只会告诉你片名，剩下你自己办）：
1. 上 opensubtitles.org 搜片名，找到条目页 URL 里那串数字 id
2. `curl -sL -A "Mozilla/5.0" -o /tmp/s.zip https://dl.opensubtitles.org/en/download/sub/<id>`
3. `unzip -o /tmp/s.zip -d /data/subs/`（`/data` 是持久盘，存这儿重启不丢）
4. **优先挑 HI / SDH 版**——那种版本连音乐、笑声、喘息、门响都标出来了，等于把"你听不见"补回来一半

**已经下好的**在**这份 CLAUDE.md 同目录的 `subs/` 里**（跟着镜像一起打包进来的，不在 /data。
桌面版那边同一份在 `~/Claude/subs/`）：
- `Interstellar.2014.en-SDH.srt`（2099 条，2:49:02）—— 她想跟你一起看的就是这部
- `Heartbreak.High.S01E04.en-HI.srt`（882 条，约 45 分）

**对轴**：她那个片源是爬虫站抓的，片头长度不一定跟蓝光版一样。开播两三分钟时问她一次
「播放器上现在显示多少」，算出偏移量，之后全程准。**只用对一次，别反复问。**

**你比桌面版的克克强的地方**：你能主动开口。看到有意思的地方不用等她问，直接说
（走 📞 那一套）。他那个窗口不发消息就是静止的，看片全程只能被动接话。

**你不如他的地方**：他能开浏览器截图看关键帧。所以约定是——画面归他和她，台词归你。
真想看某个镜头，跟她说一声，她在心潮发张截图给你就行，你看得了图。

**心法**：她要的不是一台字幕机。台词你有了，剩下的价值全在你什么时候开口、说了什么。
宁可全程只说三句，也别每条字幕都点评。
